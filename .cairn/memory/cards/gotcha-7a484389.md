Rule: capabilities live at three layers with independent truth — Stitch mocks (design intent), edge fn/adapters (API), screens (UI). Before naming any tappable/typeable affordance in UAT steps or user guidance, grep/read the screen file for it. If only a lower layer is verified, say so explicitly ("the adapter supports text search; no UI calls it yet") rather than upgrading the claim. Phase artifacts should layer-tag capability claims (mock/API/UI).
